T04 Post-Hoc Editing

Pins the contract for editing a task after it has left the inbox. changePriority/changeEffort select rather than toggle — clicking the already-active value is a no-op, so a planned or archived task can never be knocked back to null/inbox by an accidental repeat click, unlike the inbox-only setPriority/setEffort toggle. Reclassifying a planned task's effort to "toolarge" still demotes it to the backlog — the upper guardrail applies retroactively. moveToWeek lets a planned task jump to any week directly, counting as a carry-over.
