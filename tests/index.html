LocalWorkTracker — test pages

Each page runs its assertions on load and renders a pass/fail table. Open one and read the table, or run all of them headless with npm test.

Serve the repository rather than opening file:// URLs — some pages need a real origin for localStorage:
npx http-server . -p 8765 -c-1 then browse to http://localhost:8765/tests/.
