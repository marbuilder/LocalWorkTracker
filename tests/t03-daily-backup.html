T03 Daily Backup

Pins the backup-due contract. backupIntervalDays (default 1, 0 = disabled) is compared against the whole days since lastBackupDate — not a plain date-inequality check, so a 3-day interval does not fire every day. A download that raises no exception is treated as success and marks the day — a page cannot observe whether the file actually landed on disk. A download that throws leaves the date untouched and raises the banner, and only a real click can clear it.
